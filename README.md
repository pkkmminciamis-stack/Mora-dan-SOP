# SOP Madrasah Generator

Aplikasi generator Standar Operasional Prosedur (SOP) untuk Madrasah menggunakan AI.

## Fitur
- Pembuatan SOP Otomatis dengan AI
- Pratinjau Dokumen Real-time
- Ekspor ke PDF dan Word
- Manajemen Versi
- Edit Prosedur Langsung

## Cara Penggunaan
1. Isi identitas Madrasah.
2. Deskripsikan aktivitas SOP pada menu ENTRY DATA.
3. Gunakan AI untuk melengkapi detail prosedur.
4. Periksa dan simpan di menu PREVIEW.
